# CS50 Cybersecurity Portfolio

Practical implementations of core defensive engineering concepts, built using Python while completing **Harvard University's CS50 Introduction to Cybersecurity**.

## 📁 Repository Contents

### 🔐 Week 2: Securing Data (`crack.py`)
* **Concept:** Cryptographic security and computational complexity.
* **Implementation:** A Python utility that loops through character matrices (letters, numbers, punctuation symbols) to simulate brute-force pattern execution against access barriers.

### 🛡️ Week 3: Securing Software (`secure_app.py`)
* **Concept:** Injection vulnerabilities and input validation architecture.
* **Implementation:** A comparative script demonstrating defensive coding structures (parameterized queries) used to neutralize exploit inputs like SQL Injection strings.
